6. OS lab procedure and viva preparation

Aim

To simulate CPU scheduling algorithms and calculate Completion Time (CT), Turnaround Time (TAT), and Waiting Time (WT) for a given set of processes.

Procedure

  1. Enter each process ID, arrival time, and CPU burst time.
  2. Select an algorithm: FCFS, non-preemptive SJF, Round Robin, SRTF, or MLFQ.
  3. For Round Robin, enter a positive time quantum.
  4. Run the simulation and observe the Gantt chart and operation log.
  5. Record CT, TAT, and WT for every process.
  6. Compare average waiting and turnaround times across algorithms.

General pseudocode

START Read n processes: PID, Arrival Time, Burst Time Select scheduling algorithm WHILE unfinished processes exist: Find processes that have arrived Choose the next process using the selected policy Allocate CPU (whole burst or time quantum) Update remaining burst time and current time If a process finishes: CT = current time TAT = CT - Arrival Time WT = TAT - Burst Time END WHILE Calculate average TAT and average WT Display Gantt chart and process table STOP

Algorithm rules

  • FCFS: Run arrived processes in order of arrival.
  • SJF: Among arrived processes, choose the smallest burst time; run it to completion.
  • Round Robin: Give each ready process up to one time quantum, then move unfinished processes to the queue's end.
  • SRTF: Always run the arrived process with the shortest remaining time.
  • MLFQ: Start processes in the highest-priority queue; unfinished processes move to lower-priority queues.

Reference C program – FCFS

This compact C program demonstrates FCFS calculations. The browser simulator supports all five algorithms listed above.

#include <stdio.h> int main(void) { int n, i, j, time = 0; int at[20], bt[20], ct[20], tat[20], wt[20]; int done[20] = {0}; float avg_tat = 0, avg_wt = 0; printf("Enter number of processes: "); scanf("%d", &n); for (i = 0; i < n; i++) { printf("Enter arrival and burst time for P%d: ", i + 1); scanf("%d%d", &at[i], &bt[i]); } for (j = 0; j < n; j++) { int pick = -1; for (i = 0; i < n; i++) { if (!done[i] && (pick == -1 || at[i] < at[pick])) pick = i; } if (time < at[pick]) time = at[pick]; time += bt[pick]; ct[pick] = time; tat[pick] = ct[pick] - at[pick]; wt[pick] = tat[pick] - bt[pick]; done[pick] = 1; avg_tat += tat[pick]; avg_wt += wt[pick]; } printf("\\nPID\\tAT\\tBT\\tCT\\tTAT\\tWT\\n"); for (i = 0; i < n; i++) printf("P%d\\t%d\\t%d\\t%d\\t%d\\t%d\\n", i + 1, at[i], bt[i], ct[i], tat[i], wt[i]); printf("Average TAT = %.2f\\n", avg_tat / n); printf("Average WT = %.2f\\n", avg_wt / n); return 0; }

Frequently asked viva questions

1. What is CPU scheduling?
It is the OS method of selecting a ready process to execute on the CPU.

2. What is a Gantt chart?
A timeline showing which process uses the CPU over time.

3. Define turnaround time.
Total time from process arrival to completion: TAT = CT − AT.

4. Define waiting time.
Total time spent waiting in the ready queue: WT = TAT − BT.

5. What is starvation?
Indefinite waiting when a process is repeatedly denied CPU time.

6. Which algorithm is preemptive?
Round Robin and SRTF are preemptive. FCFS and the SJF mode shown here are non-preemptive.

7. What is time quantum?
The maximum CPU time given to a process in one Round Robin turn.

8. What is context switching?
Saving one process's state and restoring another process's state so the CPU can switch execution.
